# 🚀 CareFlow Dashboard — Quick Launch & Deployment Guide

This guide explains how to launch and present the Member 3 Streamlit Clinical Process Mining Dashboard.

---

## ⚙️ Prerequisites

Ensure Python 3.10+ and Node.js are installed on your environment.

```bash
# Clone repository
git clone [https://github.com/mrcrackhari/CareFlow-Clinical-Process-Mining.git](https://github.com/mrcrackhari/CareFlow-Clinical-Process-Mining.git)
cd CareFlow-Clinical-Process-Mining

# Install required dependencies
pip install pandas streamlit plotly
